                      第 06 讲回顾：读数能信吗

                      Review: Network Measurement

                      三层 · 延迟、丢包与路径四层 · 连接与吞吐

                      课程导读：第五讲回顾追问“能互通之后还缺什么”，答案是容量与映射；这一讲换一个问法：手里的读数能不能信。同一对主机可以读出 0.2 ms 或 121 ms，也可以读出 19、47 或 95 Mbit/s，这些数都是真的。用体检单五要素串起第六讲讲义：定义 → 方法 → 条件 → 不确定度 → 判断。最后用一组补测看四种常见的“读数陷阱”：算法、多路径、并发和工具的位置。
